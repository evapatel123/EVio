# EVio ✨

An in-progress gradio-based app that helps graduating high school students in their transition to college.

## Overview

EVio is a gradio-based application designed to support high school seniors during one of life's most pivotal transitions. The platform provides resources, guidance, and tools to help students navigate the complexities of college preparation and selection.

## Project Purpose

This application aims to address key challenges that graduating high school students face, including:
- Understanding college options and selection criteria
- Preparing for the college application process
- Exploring different fields of study and career paths
- Managing the transition timeline and deadlines
- Accessing reliable information and resources

## Tech Stack

- **Frontend/Backend**: Gradio (Python-based web framework)
- **Primary Language**: Jupyter Notebook (95.6%)
- **Markup**: HTML (4.4%)
